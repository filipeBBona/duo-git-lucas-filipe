# Reflexão

O conflito aconteceu porque nós dois modificamos a primeira linha do arquivo `README.md` ao mesmo tempo, criando alterações diferentes na mesma parte do arquivo.

Para decidir qual versão manter, conversamos e escolhemos a versão que fazia mais sentido para o projeto, resolvendo o conflito manualmente antes de fazer o commit.

Em um projeto real com várias pessoas trabalhando no mesmo arquivo, tentaríamos dividir melhor as tarefas, criar branches para cada alteração e fazer commits frequentes. Também poderíamos combinar previamente quem ficará responsável por cada parte do arquivo para diminuir a chance de conflitos.
